### 🐾 [Catfeína](https://github.com/dicotomia/catfeina) — Aplicación Web Full Stack <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Animals/Cat%20Face.png" alt="Cat Face" width="30" /> <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Food/Hot%20Beverage.png" alt="Hot Beverage" width="30" /> <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Shopping%20Cart.png" alt="Shopping Cart" width="30" />

Plataforma integral para un catcafé con sistema de adopciones, reservas, e-commerce benéfico y pasarela de pago.
* **Arquitectura:** Control de accesos basado en roles (RBAC) para administración diferenciada.
* **DevOps:** Contenedores con **Docker** para consistencia del entorno y despliegue automatizado en servidor VPS.
* **Tecnologías:** Node.js, Express, MySQL, Tailwind CSS.
